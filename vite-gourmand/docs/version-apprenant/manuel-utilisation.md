# Manuel d'utilisation - Vite & Gourmand

## 1. Présentation

Ce manuel explique comment utiliser l'application Vite & Gourmand.

L'application permet de consulter des menus de traiteur, de créer un compte et de passer une commande.

## 2. Accès au projet

En local, le front-end se lance avec :

```text
http://localhost:5173
```

Le back-end local est dans le dossier :

```text
server
```

Le site déployé sur Netlify sera accessible ici :

<https://startling-bonbon-2b9ff8.netlify.app>

## 3. Page d'accueil

La page d'accueil présente le service Vite & Gourmand.

On y trouve :

- une présentation du traiteur ;
- des boutons pour voir les menus ;
- des menus mis en avant ;
- des liens de navigation.

## 4. Catalogue des menus

La page catalogue permet de voir les menus disponibles.

Pour chaque menu, on peut voir :

- le titre ;
- la description ;
- le prix ;
- le type de menu ;
- une image.

## 5. Détail d'un menu

La page détail donne plus d'informations sur un menu.

Elle aide l'utilisateur à choisir avant de commander.

## 6. Inscription

Un visiteur peut créer un compte.

Il doit remplir les informations demandées dans le formulaire.

## 7. Connexion

Un utilisateur peut se connecter avec son email et son mot de passe.

Comptes de test prévus :

| Rôle | Email | Mot de passe |
| --- | --- | --- |
| Administrateur | `admin@vitegourmand.fr` | `Admin123!` |
| Employé | `lucas@demo.fr` | `Admin123!` |
| Utilisateur | `claire@demo.fr` | `Admin123!` |

## 8. Commande

L'utilisateur connecté peut passer une commande.

Il choisit un menu et renseigne les informations nécessaires.

## 9. Tableau de bord

Le tableau de bord permet de voir les informations du compte.

Selon le rôle, il peut afficher :

- les commandes ;
- les avis ;
- les utilisateurs ;
- les statistiques.
