# Charte graphique - Vite & Gourmand

## 1. Présentation

Cette charte explique les choix visuels du projet Vite & Gourmand.

Le but est d'avoir une interface claire, agréable et cohérente.

## 2. Ambiance générale

L'application doit donner une impression :

- sérieuse ;
- simple ;
- gourmande ;
- rassurante.

Je veux que l'utilisateur comprenne rapidement où cliquer.

## 3. Couleurs

Les couleurs servent à organiser l'interface.

Il faut prévoir :

- une couleur principale pour les boutons importants ;
- une couleur secondaire pour les détails ;
- un fond clair pour bien lire ;
- une couleur d'erreur pour les messages de formulaire ;
- une couleur de succès pour les validations.

## 4. Typographie

Les textes doivent rester faciles à lire.

Les titres doivent être visibles, mais pas trop grands.

Les boutons doivent avoir des textes simples comme :

- Voir les menus ;
- Commander ;
- Se connecter ;
- Valider.

## 5. Boutons

Les boutons doivent être faciles à trouver.

Sur mobile, ils doivent être assez grands pour être utilisés avec le doigt.

## 6. Cartes

Les menus sont affichés sous forme de cartes.

Une carte doit montrer :

- une image ;
- le nom du menu ;
- le prix ;
- une courte description ;
- un bouton pour voir le détail.

## 7. Formulaires

Les formulaires doivent être simples.

Chaque champ doit avoir un libellé clair.

Si l'utilisateur fait une erreur, un message doit l'aider à comprendre.

## 8. Navigation

La navigation doit permettre d'aller rapidement vers :

- l'accueil ;
- les menus ;
- la connexion ;
- le contact ;
- le tableau de bord.

## 9. Mobile

Sur mobile, les éléments doivent être affichés sur une seule colonne.

## 11. Conclusion

Cette charte sert à garder une interface simple et cohérente pour tout le projet.
