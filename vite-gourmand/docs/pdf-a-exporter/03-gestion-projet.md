## 1. Contexte

Le projet Vite & Gourmand est realise dans le cadre d'un ECF Studi. Il simule une application web pour une activite de traiteur.

## 2. Objectifs

Objectifs :

- creer une application responsive ;
- permettre la consultation de menus ;
- gerer les commandes ;
- proposer des espaces par role ;
- documenter et deployer le projet.

## 3. Acteurs

- Visiteur.
- Utilisateur/client.
- Employe.
- Administrateur.
