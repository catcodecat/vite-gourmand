## 1. Contexte

Vite & Gourmand est une application web de traiteur fictif realisee pour un ECF Studi.

## 2. Objectifs

L'application doit permettre de consulter des menus, creer un compte, passer commande et acceder a des espaces par role.

## 3. Public cible

- Visiteur.
- Utilisateur/client.
- Employe.
- Administrateur.

## 4. Besoins

Besoins principaux :

- catalogue ;
- detail menu ;
- inscription ;
- connexion ;
- commande ;
- dashboards ;
- gestion utilisateurs ;
- avis ;
- analytics.

## 5. Contraintes

Contraintes :

- base SQL ;
- base NoSQL ;
- documentation ECF ;
- deploiement front Netlify ;
- API Express separee ;
- securite minimale.
