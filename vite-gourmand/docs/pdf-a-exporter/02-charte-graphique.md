## 1. Identite visuelle

Vite & Gourmand doit transmettre une image professionnelle, gourmande et rassurante. L'interface doit rester claire et adaptee a un service de commande traiteur.

## 2. Couleurs

Les couleurs servent a distinguer :

- actions principales ;
- informations secondaires ;
- messages de succes ;
- messages d'erreur ;
- statuts des commandes.

## 3. Typographie

La typographie doit etre lisible sur desktop et mobile. Les titres structurent les pages, les textes restent courts et les boutons utilisent des intitules directs.

## 4. Composants

Composants principaux :

- navigation ;
- boutons ;
- cartes menus ;
- formulaires ;
- dashboards ;
- toasts ;
- footer.

## 5. Responsive

Sur mobile, les cartes passent en colonne, les boutons deviennent plus larges et les tableaux sont remplaces par des blocs lisibles.
