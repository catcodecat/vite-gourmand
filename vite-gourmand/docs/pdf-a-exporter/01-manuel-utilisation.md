## 1. Presentation

Vite & Gourmand est une application web de traiteur. Elle permet de consulter des menus, creer un compte, passer commande et suivre les informations depuis un tableau de bord.

## 2. Acces a l'application


Production :

## 3. Parcours visiteur

Le visiteur peut :

- consulter la page d'accueil ;
- consulter le catalogue ;
- voir le detail d'un menu ;
- acceder a l'inscription ;
- envoyer un message de contact.

## 4. Parcours utilisateur

L'utilisateur connecte peut :

- se connecter ;
- passer une commande ;
- consulter son dashboard ;
- suivre ses commandes.

## 5. Espaces employe et administrateur

L'employe peut suivre les commandes et participer a leur gestion. L'administrateur peut gerer les utilisateurs, les employes, les avis et les statistiques.
