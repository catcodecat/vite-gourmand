## 1. Presentation

Vite & Gourmand est une application web de traiteur fictif creee pour un ECF Studi.

## 2. Objectifs

Objectifs :

- proposer un catalogue ;
- permettre la commande ;
- gerer plusieurs roles ;
- utiliser SQL et NoSQL ;
- documenter et deployer le projet.

## 3. Choix techniques

Stack :

- React / Vite ;
- Node.js / Express ;
- MySQL ;
- MongoDB ;
- Netlify.

## 4. Developpement

Le projet est organise entre `src/`, `server/`, `database/`, `docs/` et `dist/`.

## 5. Tests et deploiement

Les tests sont documentes dans `docs/tests-recette.md`. Le front-end est prevu pour Netlify avec publication du dossier `dist`.

## 6. Limites et ameliorations

Limites :

- API de production a confirmer ;
- captures a realiser ;
- exports PDF a produire.

Ameliorations :

- tests automatises ;
- Swagger ;
- paiement ;
- accessibilite ;
- RGPD.

## 7. Conclusion

Le projet presente une base solide pour un rendu ECF : application, documentation, bases de donnees, maquettes, diagrammes, tests et deploiement.
