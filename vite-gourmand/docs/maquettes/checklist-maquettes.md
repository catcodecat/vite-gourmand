# Checklist maquettes - Vite & Gourmand

## 1. Objectif

Cette checklist permet de suivre les captures ou exports de maquettes a produire pour le dossier ECF Studi.

Les maquettes peuvent etre finalisees dans Figma, Canva, Penpot ou a partir des captures de l'application integree.

## 2. Captures ou exports desktop

| Element | Statut | Fichier / support | Commentaire |
| --- | --- | --- | --- |
| Accueil desktop | A faire | Export image ou PDF | Montrer la page d'accueil complete sur ordinateur. |
| Catalogue desktop | A faire | Export image ou PDF | Montrer la page catalogue / menus avec plusieurs cartes visibles. |
| Dashboard desktop | A faire | Export image ou PDF | Montrer le tableau de bord utilisateur ou administrateur. |

## 3. Captures ou exports mobile

| Element | Statut | Fichier / support | Commentaire |
| --- | --- | --- | --- |
| Accueil mobile | A faire | Export image ou PDF | Montrer l'adaptation responsive de la page d'accueil. |
| Catalogue mobile | A faire | Export image ou PDF | Montrer les menus en affichage mobile. |
| Dashboard mobile | A faire | Export image ou PDF | Montrer les informations du tableau de bord en cartes ou blocs. |

## 4. Documents de preparation

| Element | Statut | Fichier concerne | Commentaire |
| --- | --- | --- | --- |
| Wireframes desktop | Fait | `docs/maquettes/wireframes.md` | Accueil, catalogue, dashboard. |
| Wireframes mobile | Fait | `docs/maquettes/wireframes.md` | Accueil, catalogue, dashboard. |
| Description mockups desktop | Fait | `docs/maquettes/mockups.md` | Couleurs, typographie, boutons, cartes, navigation. |
| Description mockups mobile | Fait | `docs/maquettes/mockups.md` | Adaptation responsive documentee. |

## 5. Emplacements recommandes dans le dossier ECF

Les captures ou exports peuvent etre ajoutes dans :

```text
docs/assets/maquettes/
```

Noms de fichiers conseilles :

```text
accueil-desktop.png
catalogue-desktop.png
dashboard-desktop.png
accueil-mobile.png
catalogue-mobile.png
dashboard-mobile.png
```

## 6. Points de verification

Avant export final, verifier :

- lisibilite des titres ;
- coherence des couleurs ;
- boutons visibles ;
- cartes de menus comprehensibles ;
- navigation claire ;
- affichage mobile sans debordement horizontal ;
- presence des 3 maquettes desktop ;
- presence des 3 maquettes mobile.

## 7. Conclusion

Les documents de preparation des maquettes sont disponibles. Il reste a produire ou capturer les visuels finaux pour les integrer au dossier PDF ECF.
