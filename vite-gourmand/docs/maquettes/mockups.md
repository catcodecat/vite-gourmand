# Mockups - Vite & Gourmand

## 1. Objectif

Ce document prepare la description des mockups du projet Vite & Gourmand.

Les mockups correspondent a la version visuelle des wireframes : choix de couleurs, typographie, boutons, cartes, navigation et hierarchie visuelle.

## 2. Mockups desktop prevus

Trois mockups desktop sont prevus :

1. Page d'accueil.
2. Page catalogue / menus.
3. Tableau de bord utilisateur ou administrateur.

## 3. Mockups mobile prevus

Trois mockups mobile sont prevus :

1. Page d'accueil mobile.
2. Page catalogue / menus mobile.
3. Tableau de bord mobile.

## 4. Direction graphique generale

L'application doit inspirer confiance et gourmandise, tout en restant lisible et professionnelle.

Intentions visuelles :

- interface claire ;
- cartes de menus visibles ;
- images appetissantes ;
- boutons bien identifies ;
- hierarchie simple entre titres, textes et actions ;
- experience rassurante pour la commande.

## 5. Couleurs

Les couleurs doivent rester coherentes avec la charte graphique.

Usages recommandes :

- couleur principale pour les boutons d'action ;
- couleur secondaire pour les badges et accents ;
- fonds clairs pour les pages de consultation ;
- contraste suffisant entre texte et fond ;
- couleur d'erreur pour les messages de formulaire ;
- couleur de validation pour les actions reussies.

## 6. Typographie

La typographie doit etre lisible et adaptee aux ecrans.

Principes :

- titres visibles ;
- sous-titres courts ;
- paragraphes lisibles ;
- labels de formulaires explicites ;
- textes de boutons directs.

## 7. Boutons

Les boutons doivent guider l'utilisateur.

Types de boutons :

- bouton principal : commander, se connecter, voir les menus ;
- bouton secondaire : voir le detail, revenir, annuler ;
- bouton d'administration : modifier statut, valider avis, creer employe.

Les boutons doivent etre visibles sur desktop et faciles a toucher sur mobile.

## 8. Cartes

Les cartes servent principalement a afficher :

- menus ;
- avis ;
- commandes ;
- statistiques.

Une carte doit contenir :

- un titre ;
- une information principale ;
- une action claire si necessaire ;
- une image pour les menus.

## 9. Formulaires

Les formulaires concernent notamment :

- connexion ;
- inscription ;
- commande ;
- contact ;
- creation d'employe.

Principes UX :

- champs alignes ;
- labels visibles ;
- messages d'erreur simples ;
- bouton de validation identifiable ;
- retour utilisateur apres soumission.

## 10. Navigation

### Desktop

La navigation desktop doit afficher les liens principaux :

- accueil ;
- menus ;
- contact ;
- connexion ou espace compte.

### Mobile

La navigation mobile doit etre compacte.

Elle peut prendre la forme :

- d'un menu ;
- d'une liste de liens ;
- d'une navigation simplifiee.

## 11. Hierarchie visuelle

La hierarchie doit aider l'utilisateur a comprendre l'ecran rapidement.

Ordre de priorite :

1. titre de page ;
2. action principale ;
3. informations essentielles ;
4. actions secondaires ;
5. informations complementaires.

## 12. Mockup desktop - Page d'accueil

### Couleurs

Fond clair, accents de marque sur les boutons et elements importants.

### Typographie

Grand titre d'accueil, texte court, titres de sections lisibles.

### Boutons

- Voir les menus.
- Commander.
- Voir le detail d'un menu.

### Cartes

Cartes de menus avec image, titre, prix et bouton.

### Navigation

Barre de navigation horizontale.

### Experience utilisateur

L'utilisateur doit comprendre rapidement l'offre et acceder au catalogue.

## 13. Mockup desktop - Catalogue / menus

### Couleurs

Fond neutre pour valoriser les cartes et les images.

### Typographie

Titre de page clair, informations de prix bien visibles.

### Boutons

- Voir le detail.
- Commander.
- Appliquer les filtres si necessaire.

### Cartes

Grille de cartes menus avec image, theme, regime alimentaire et prix.

### Navigation

Header fixe ou visible en haut de page.

### Experience utilisateur

L'utilisateur doit pouvoir comparer les menus facilement.

## 14. Mockup desktop - Tableau de bord

### Couleurs

Interface plus fonctionnelle, avec couleurs de statut pour les commandes.

### Typographie

Titres compacts, tableaux lisibles, statuts visibles.

### Boutons

- Modifier statut.
- Valider.
- Annuler.
- Voir details.

### Cartes

Cartes statistiques et zones de resume.

### Navigation

Sidebar ou navigation secondaire pour les sections du compte.

### Experience utilisateur

L'utilisateur doit retrouver rapidement ses commandes ou actions prioritaires.

## 15. Mockup mobile - Page d'accueil

### Couleurs

Conserver les couleurs du desktop, avec contraste renforce pour les boutons.

### Typographie

Titre plus compact, texte court.

### Boutons

Boutons empiles sur toute la largeur disponible.

### Cartes

Cartes menus en colonne.

### Navigation

Menu mobile simplifie.

### Experience utilisateur

Acces rapide aux menus et a la commande.

## 16. Mockup mobile - Catalogue / menus

### Couleurs

Fond clair et cartes separees visuellement.

### Typographie

Prix et titres de menus bien visibles.

### Boutons

Bouton detail accessible sur chaque carte.

### Cartes

Une carte par ligne, avec image et informations essentielles.

### Navigation

Bouton de filtres compact.

### Experience utilisateur

La consultation doit rester fluide sans tableau ni grille trop large.

## 17. Mockup mobile - Tableau de bord

### Couleurs

Couleurs de statut visibles mais sobres.

### Typographie

Informations de commande lisibles en petits blocs.

### Boutons

Actions tactiles, bien espacees.

### Cartes

Les commandes sont affichees sous forme de cartes.

### Navigation

Onglets, menu compact ou boutons empiles.

### Experience utilisateur

L'utilisateur doit suivre ses commandes sans zoomer ni faire defiler horizontalement.

## 18. Conclusion

Ces descriptions permettent de produire les six mockups attendus : trois desktop et trois mobile. Les maquettes peuvent etre finalisees dans Figma, Canva, Penpot ou a partir de captures de l'application integree.
