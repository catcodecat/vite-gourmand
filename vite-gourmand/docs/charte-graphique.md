# Charte graphique - Vite & Gourmand

## 1. Objectif

Cette charte graphique presente les choix visuels du projet Vite & Gourmand pour le dossier ECF Studi.

Elle sert de reference pour garantir une interface coherente entre les pages de l'application.

## 2. Identite visuelle

Vite & Gourmand est une marque fictive de traiteur. L'identite doit transmettre :

- confiance ;
- gourmandise ;
- qualite de service ;
- modernite ;
- accessibilite.

## 3. Ton graphique

Le style graphique est sobre, professionnel et oriente service.

Le design doit permettre :

- une consultation rapide des menus ;
- une lecture claire des prix et informations ;
- une navigation simple ;
- une experience rassurante pour la commande.

## 4. Couleurs

Les couleurs exactes sont definies dans le front-end via Tailwind CSS et les styles du projet.

Palette fonctionnelle recommandee pour le dossier :

| Usage | Description |
| --- | --- |
| Couleur principale | Utilisee pour les boutons principaux, liens actifs et elements de marque. |
| Couleur secondaire | Utilisee pour les accents, badges ou elements complementaires. |
| Fond clair | Utilise pour la lisibilite des pages. |
| Texte principal | Utilise pour les titres et paragraphes. |
| Texte secondaire | Utilise pour les descriptions et informations moins prioritaires. |
| Couleur succes | Utilisee pour les validations et confirmations. |
| Couleur alerte | Utilisee pour les erreurs ou informations importantes. |

## 5. Typographie

L'interface utilise une typographie web lisible et adaptee aux ecrans.

Principes :

- titres visibles et hierarchises ;
- paragraphes courts ;
- boutons lisibles ;
- labels de formulaires explicites ;
- tailles adaptees au desktop et au mobile.

## 6. Iconographie

Les icones servent a renforcer la comprehension des actions.

Usages possibles :

- navigation ;
- actions utilisateur ;
- etats de commande ;
- tableaux de bord ;
- messages de confirmation ou d'erreur.

## 7. Images

Les images de menus valorisent l'univers traiteur.

Regles conseillees :

- images nettes ;
- cadrage appetissant ;
- coherence entre les menus ;
- textes alternatifs pour l'accessibilite.

## 8. Composants d'interface

Composants detectes dans le projet :

- barre de navigation ;
- footer ;
- cartes de menus ;
- cartes d'avis ;
- boutons ;
- champs de formulaire ;
- modales ;
- toasts de notification ;
- loaders ;
- sidebar de tableau de bord ;
- section de statistiques.

## 9. Formulaires

Les formulaires doivent etre simples et explicites.

Bonnes pratiques :

- labels clairs ;
- messages d'erreur visibles ;
- champs obligatoires identifiables ;
- retour utilisateur apres validation ;
- protection des donnees sensibles.

[Capture à insérer : connexion]

## 10. Tableaux de bord

Les tableaux de bord doivent privilegier la lisibilite et l'efficacite.

Principes :

- informations importantes visibles rapidement ;
- statuts de commandes comprehensibles ;
- actions administrateur identifiables ;
- mise en page claire.

[Capture à insérer : tableau de bord]

## 11. Responsive design

L'application doit rester utilisable sur mobile.

Points a verifier :

- menu de navigation ;
- largeur des cartes ;
- lisibilite des formulaires ;
- boutons accessibles ;
- absence de debordement horizontal.

[Capture à insérer : version mobile]

## 12. Accessibilite

Principes appliques ou a verifier :

- contraste suffisant ;
- textes alternatifs sur les images ;
- navigation claire ;
- messages d'erreur comprehensibles ;
- boutons avec intitules explicites.

## 13. Conclusion

La charte graphique de Vite & Gourmand repose sur une interface claire, moderne et rassurante, adaptee a une application de commande traiteur.
