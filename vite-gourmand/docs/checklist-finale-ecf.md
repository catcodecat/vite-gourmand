## Points a completer manuellement avant rendu

- Verifier que le lien Notion est accessible publiquement ou partage avec le jury.
- Confirmer l'hebergement de l'API si elle est utilisee en production.
- Executer les tests et remplacer les statuts `A verifier` par `OK` ou `KO`.
- Realiser les captures d'ecran finales.
- Exporter les documents demandes au format PDF.
- Verifier les branches Git sur GitHub.
- Rechercher les placeholders restants avant remise.
